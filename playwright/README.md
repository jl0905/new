WARNING: This is only compatible with windows for now.

cd into this folder, then run `npm run auth` with chrome installed. Then log
into GrubHub. Then, leave chrome open and run `npm run scrape <index>` where
`<index>` is an index into the list in addresses.json. The script will then
pull data about that restaurant.

Eventually, I want this to also pull menu items and add them to the db.
